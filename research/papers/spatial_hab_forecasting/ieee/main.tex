\title{Spatial Context Did Not Help: A U-Net Loses to a Per-Cell Tree Model
for Harmful-Algal-Bloom Forecasting, Measured Twice}

\author{\IEEEauthorblockN{Deepak Krishna}
\IEEEauthorblockA{\textit{MarisAI} \\
India \\
deepakkrishna2206@gmail.com}}

\maketitle

\begin{abstract}
A per-cell classifier forecasting harmful-algal-bloom risk cannot see an
eddy, a front, or the shape of a bloom spanning several grid cells --- the
standard architectural objection to per-cell models, and the standard
argument for a convolutional alternative. We test that objection directly:
a single-frame U-Net given a \NInputChannels{}-channel ocean-state image
(\NChannels{} physical fields, each paired with an observed-mask channel)
is trained to forecast t+3 bloom probability and scored against the
existing per-cell LightGBM model, reloaded and rescored on the U-Net's own
\NTestRows{} test rows so the comparison is identical-row rather than
merely same-sized. The U-Net beats a persistence baseline (PR-AUC
\UnetPRAUC{} vs.\ \PersistPRAUC{}) but loses clearly to LightGBM
(\LgbmPRAUC{}) on every one of four metrics. We re-ran the full pipeline
live while writing this paper and reproduce the original measurement to
three to four decimal places, and report an unrelated engineering hazard
found in building the comparison: importing \texttt{torch} before loading a
LightGBM artifact with \texttt{joblib} in the same process segfaults with
no traceback, which is why the tabular baseline is scored in a subprocess.
The negative result is evidence against reaching for a spatiotemporal
architecture (ConvLSTM) next, since this agenda item was deliberately
ordered to make that inference available from a single-frame test.
\end{abstract}
